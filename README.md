# MCP Nexus

> A local Model Context Protocol hub: chat with Claude, OpenAI or Ollama models, plug in Python connectors as MCP tools, dispatch webhooks and emails with human approval, manage prompt templates, and watch every JSON-RPC message live.

🚧 **Work in progress.** See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the design and [`docs/DEVLOG.md`](docs/DEVLOG.md) for build progress. The full README with a quickstart lands in Phase 5.
